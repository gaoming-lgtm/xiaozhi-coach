# 小智师傅 · 装机陪练

本地跑的装机搭子。右边是 3D 示意台，左边是对话，底下是步骤卡。
你装错了他看得见（你拍照），你手占着他能听（语音），你卡住了他一步步带。

不是通用助手，是**只装小智**的专用工具：接线全来自一份核对过的蓝图，模型只能引用，不能自己编。

---

## 跑起来

```powershell
cd xiaozhi-coach
node server.mjs
```

浏览器会自动打开，地址形如 `http://127.0.0.1:7842/?t=<token>`。
**这个带 token 的链接只打印一次**，丢了就重启服务。

### 填 Key（不填就只能看不能聊）

**在网页上填，不用碰文件**：打开右上角的 `🔑 Key`，粘进去，回车。

存哪了？写进 `xiaozhi-coach/config.json` 的 `apiKey` 字段。想清空就在同一个框里清空再保存。

也可以不改文件，用环境变量：

```powershell
$env:DEEPSEEK_API_KEY = "sk-……"
node server.mjs
```

> 这个 Key 是 **DeepSeek 的 API Key**，不是小智的设备码，跟 `xiaozhi.me` 后台没关系。
> 在 `platform.deepseek.com` → API keys 里建，`sk-` 开头。

## 文件

```
server.mjs                    会话 / SSE / 工具循环 / 照片 / 状态机
lib/tools.mjs                 5 个工具：show_step show_3d get_wiring record_check show_checklist
prompts/coach.md              装机教练人格与安全约束
specs/xiaozhi-breadboard-oled.json   蓝图：零件 / 接线 / 步骤 / 验收标准
public/scene3d.js             程序化 3D（不加载任何外部模型或贴图）
public/app.js                 前端
public/vendor/three.module.min.js    Three.js r160（本地，离线可用）
```

**这个项目里没有任何能执行命令、写文件的工具。** 装机的风险在手上，不在电脑上，所以工具集故意做窄了。

## 蓝图怎么写

`specs/*.json` 是唯一的知识来源。加一个新板型 = 加一份 JSON，3D 和流程会自动跟着变。

- `wiring[]`：每条线的 `from` / `to` / 颜色 / 备注。**模型只能读，不能改。**
- `steps[]`：每步有 `goal`（目标）、`why`（为什么）、`do`（怎么做）、`check`（拍照验收标准）、`pitfalls`（坑）、`safety`。
- `safety: "danger"` 的步骤，步骤卡会变红边框。

改完 JSON 不用改代码，刷新页面就是新的。

## 已知限制

1. **看图要用 flash。** `deepseek-v4-pro` 不收图（会把图片当成 `[Unsupported Image]`），`deepseek-flash` 能看。
   所以照片会先交给 `deepseek-flash` 转成文字描述，再把描述喂给 `v4-pro` 干正事——主模型仍然是最强的那个。
   换模型在 `config.json` 的 `visionModel` 字段。
2. **3D 是示意级，不是写实。** 零件是方块和圆柱，位置是按逻辑摆的，不是实物 1:1 还原。教接线够用。
3. **认照片靠模型转述。** 小零件、暗光、手抖时会看不清，这时他会让你重拍，而不是瞎猜。
4. **只支持一份蓝图。** 换板型要新写 spec。
5. **沙箱里跑不了语音**（`spawn EPERM`），自己开终端跑就正常。
